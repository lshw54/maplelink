## 下载来源提醒 {#2026-09-download-source}
我们接获反馈，有非官方、疑似被重新打包的 Beanfun 启动器在外流传。

开发团队每次发布，只会提供 GitHub 上该版本 exe 的下载链接。我们给的永远是链接，不是文件。

所以，如果有人直接把可执行文件传给你，或者你从网盘、论坛转载、聊天群组附件取得，那就不是我们发出的。MapleLink 与 Beanfun 各自独立发布，任何一边都不会代另一边派发文件。

下载与使用前，请先确认来源安全可靠。不是从认可位置取得的，请立即删除并重新下载。重新打包的版本可能已被植入其他程序，而你的账号密码会经过它。

## 开发状态与双线更新公告 {#2026-07-dual-track}
MapleLink 目前与原版 Beanfun 维持双线并行开发，旨在为玩家提供更具弹性的选择。两个项目各有明确定位：

- **MapleLink（本项目）**：专为纯《新枫之谷》玩家打造，采用由零重写的轻量化架构，作为新技术实验与快速排查登录异常问题的先行区。
- **Beanfun**：以支持所有橘子旗下游戏为目标，持续优化并提供高兼容性的全生态服务。

## MapleLink v0.6.1 {#v0-6-1}

**新功能**

- 游戏客户端管理器可以在加速器下使用：官方清单直接向 beanfun 以 HTTPS 获取，连接按照 Windows 系统代理
- 清单来源可选自动、beanfun 或 HiNet 目录，自动模式会记住可用的来源；新增「测试来源」
- 修复时每个文件各有进度条，清单实时更新，完成的文件自动取消勾选
- 可以设置同时下载的文件数
- 窗口顶部显示官方版本、本机客户端、磁盘空间与网络状态
- 额外文件可以勾选后移至回收站

**更安全**

- 只接受下载地址为 beanfun 官方 CDN（HTTPS）的清单，被改过的清单副本会被拒绝
- 清理额外文件时不会跟随链接，也不会移走官方清单上的文件

**修正**

- 单个文件连接中断时自动重试，不再导致整次修复失败
- 深色主题下的下拉菜单看不清楚
- 设置页的下拉菜单被卡片截断
- 新手引导的「跳过」点不到
- 错误信息显示 [object Object]，改为显示实际原因
- 次要文字的颜色对比不足，看不清楚

**其他**

- 官方网站的游戏客户端页面与界面演示同步更新

## MapleLink v0.6.0 {#v0-6-0}

**新功能**

- 游戏客户端管理器：按官方清单检查、修复与安装客户端
- 内置 beanfun 浏览器，带地址栏与连接信息
- 账号列表可以直接新增游戏账号
- 精简模式，工具箱一并重新整理
- 自定义主题色
- 官方网站上线，教程、下载与可试玩的界面演示都在上面

**更安全**

- 自动更新改为验证我们持有的签名，下载先保存成文件、检查通过才替换
- 连接一律验证证书，对外读取设有上限
- 不再关闭 WebView 的渲染沙箱

**修正**

- OTP 自动粘贴不再落在账号栏
- QR 登录的刷新、复制与倒计时，窗口尺寸也已调整
- Windows 用户名含非 ASCII 字符时的路径问题
- 分页的关闭与新增按钮太小
- 浏览器工具栏提示遮住地址栏

**其他**

- 内置字体只保留界面用得到的字，体积更小
- 清理无用代码，统一登录后的流程
- 依赖包安全更新
