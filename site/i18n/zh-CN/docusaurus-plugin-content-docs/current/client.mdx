# 游戏客户端

新枫之谷的完整客户端约 67 GB，官方并没有提供单一个安装包。beanfun 游戏管理器的做法，是按一份官方清单把整个游戏文件夹从官方 CDN 取回来。MapleLink 内置的「游戏客户端管理」用的是同一份清单与同一个 CDN，可以安装、检查，或只补回坏掉的文件。

:::tip 文件来源与完整性由官方把关
清单与文件全部来自 beanfun 官方，每个文件下载后都会用官方公布的 SHA-256 校验，对得上才会写入。校验不过的不会覆盖你原有的文件。

清单本身是公开的，想自己核对可以直接打开：[productInfo.json](https://maplestory-download.beanfun.com/maplestory/productInfo.json)。里面每一行的文件路径、大小与 SHA-256，就是窗口里比对用的那一份。
:::

## 在哪里打开

标题栏右上角的下载图标，或「工具箱 → 游戏客户端管理」。窗口分成两个分页：**检查与修复**、**下载与安装**。

## 自动下载安装 {#install}

在「下载与安装」分页点**自动下载安装**，选一个空文件夹，MapleLink 会直接从官方 CDN 获取整个客户端。

- 过程中可以**暂停**与**继续**，也可以取消。
- 中途关掉也不要紧：下次对同一个文件夹再检查一次，已完成的文件不会重新下载。
- 底部的**直连**默认开启，代表不经系统代理与加速器。部分线路直连反而更快；若你的环境相反，把它关掉再试。

完成后，到 MapleLink 的「设置 → 游戏路径」指向该文件夹内的 `MapleStory.exe`。

## 检查与修复 {#repair}

在「检查与修复」分页选好**游戏路径**，再点「开始检查」。

| 方式 | 做什么 | 用时 |
|---|---|---|
| 快速 | 只比对文件大小，抓得到缺失与被截断的文件 | 数秒 |
| 完整 | 校验每个文件的 SHA-256 | 视硬盘而定，SSD 约数分钟 |

检查完会列出全部文件，可以按「需要处理 / 正常 / 额外文件」筛选，或直接搜索文件名。确认要补的项目后点「下载并修复」。

:::warning 修复会覆盖对不上的文件
开始前请先关闭游戏。若你自行修改过客户端内的文件，请先备份。MapleLink 不会删除任何文件，清单以外的文件只会列出来给你参考。
:::

这个分页的游戏路径只影响这个窗口，不会改动「设置」里的游戏路径。

<details>
<summary>「文件损坏」或「版本过旧」是不是代表坏了？</summary>

状态栏会写明每个文件要换的原因：**缺失**是本机找不到，**版本过旧**是客户端比官方版本旧，**文件损坏**是版本一样但内容对不上，**无法读取**多数是文件正被占用。把光标移到状态上会看到详细说明。

对不上不一定代表坏了。官方清单是该版本的**基础**客户端，而游戏自己的更新程序会在安装后修改部分文件，最典型的就是 `MapleStory.exe`。MapleLink 认得这种情况：它会向官方更新服务器确认当前的主程序，对得上就当作正常。

若游戏目前运行正常，这类项目可以不勾选。修复会把它们还原成基础版本，游戏下次启动时通常会重新应用更新。

</details>

<details>
<summary>可以自动检查吗？</summary>

可以。第一次打开窗口时会问你要不要「每次打开时自动检查」，选了之后可以在底部的「自动检查」随时改。开启后，窗口一打开就会跑一次快速检查。

如果你有开启「阻止游戏自动更新」，被拦下来的更新提示里也有一个按钮，直接带你到这个窗口。

</details>

## 手动：用种子文件 {#torrent}

想自己控制下载，就在「下载与安装」分页点**手动：保存种子文件**，再用自己的 BT 工具打开。

1. 安装一个 BT 下载工具，例如 [qBittorrent](https://www.qbittorrent.org/)。
2. 用它打开刚才保存的种子文件，选择保存位置。根目录可以改成你想要的名称。
3. 下载完成后会得到一个完整的客户端文件夹。
4. 回到 MapleLink，在「设置 → 游戏路径」指向该文件夹内的 `MapleStory.exe`。

种子内含指向 beanfun CDN 的 web seed，即使没有其他分享者，也会直接从官方服务器下载。

同一个种子文件也可以用来修复：把保存位置指向现有客户端的**上一层**，根目录名称改成现有文件夹的名称，添加后执行「强制重新校验」，工具就只会补回对不上的部分。

## 为什么种子文件要由 MapleLink 生成 {#why}

官方那个种子文件是为游戏管理器而做的，直接拿去用会下载不到任何东西：

- 种子内记录的根目录名称与官方 CDN 的实际路径不符，一般 BT 工具会按规格去请求文件，结果每一个都找不到。
- 游戏管理器从不做种，所以也没有其他分享者可以补上。

MapleLink 只把根目录名称改成 CDN 的实际路径，其余内容一律不动，包括每一块数据的哈希值与 web seed 地址。换言之，你的下载工具仍然是以官方公布的哈希值校验每一个字节。

<details>
<summary>可以给我一条 magnet 链接吗？</summary>

不可以。magnet 链接本身只是一个指向，里面没有文件清单与哈希值，下载工具要靠其他分享者把这份数据传过来。这个种子没有任何人做种，所以用 magnet 链接只会一直停在「正在下载元数据」。

</details>

<details>
<summary>那个「游戏橘子游戏管理器」要不要装？</summary>

不建议。安装或更新它会把 `gamaniagames://` 的注册表项设回自己；若你有开启 MapleLink 的网页启动接管，接管就会失效，要回设置重新开启。安装与更新用上面两种方式已经涵盖。

</details>
