# 游戏客户端

新枫之谷的完整客户端约 67 GB，官方并没有提供单一个安装包。beanfun 游戏管理器的做法，是按一份官方清单把整个游戏文件夹从官方 CDN 取回来。MapleLink 可以把同一份来源整理成一个 BT 种子文件，让你用自己的下载工具获取，过程中不经任何第三方重新打包。

:::tip MapleLink 不会下载或改写任何游戏文件
它只会读取官方清单，生成一个种子文件让你保存。实际下载由你的下载工具直接向官方服务器进行，每一个字节都会以官方公布的哈希值校验。
:::

## 你属于哪一种情况

| 情况 | 建议 |
|---|---|
| 全新安装，或更换一台电脑 | 用下面的[完整客户端种子](#torrent) |
| 客户端损坏、更新失败、启动时提示文件损坏 | 用[修复现有客户端](#repair)，只补回对不上的部分 |
| 只想要官方安装包或更新档 | 同一个窗口下方就是 beanfun 官方链接 |

## 获取种子文件 {#torrent}

这个功能需要较新版本的 MapleLink。如果在工具箱找不到，请先更新到最新版。

1. 打开 MapleLink，点击右上角的工具箱图标。
2. 选择「下载／修复客户端」。
3. 最上方的「完整客户端（BT 种子）」会显示当前版本、容量与发布日期。
4. 点击「保存种子文件」，选一个位置存起来。

版本号与文件夹名称每次都是实时向官方读取，所以这一步永远对应当下的最新版本，不需要我们另行更新。

## 用下载工具获取客户端

1. 安装一个 BT 下载工具，例如 [qBittorrent](https://www.qbittorrent.org/)。
2. 用它打开刚才保存的种子文件。
3. 选择保存位置。你可以顺便把根目录改成自己想要的名称，例如 `MapleStory`，不会影响下载。
4. 开始下载。完成后会得到一个完整的客户端文件夹。
5. 回到 MapleLink，在「设置 → 游戏路径」指向该文件夹内的 `MapleStory.exe`。

种子内含指向 beanfun CDN 的 web seed，即使没有其他分享者，也会直接从官方服务器下载。若你使用游戏加速器，这些流量走的是 beanfun 域名，通常同样会被加速。

## 修复现有客户端 {#repair}

客户端有文件损坏时，不需要重新下载整个 67 GB。同一个种子文件可以逐块校验你现有的文件夹，只补回对不上的部分。

1. 先关闭游戏，并确认没有其他程序正在使用该文件夹。
2. 用下载工具打开种子文件。
3. 保存位置选你现有客户端文件夹的**上一层**。例如客户端在 `D:\Games\MapleStory`，这里就选 `D:\Games`。
4. 把种子的根目录名称改成你现有文件夹的名称，即上例的 `MapleStory`。
5. 添加之后，对该任务执行「强制重新校验」（qBittorrent 为右键菜单的 Force recheck）。
6. 校验完成后，工具只会重新下载对不上的部分。

:::warning 修复会覆盖对不上的文件
如果你自行修改过客户端内的文件，这一步会把它们还原成官方版本。有需要请先备份。
:::

校验以约 4 MB 为一块进行，所以补回的份量会比损坏的文件本身略多一点，但仍然远少于重新下载整个客户端。

## 为什么种子文件要由 MapleLink 生成 {#why}

官方那个种子文件是为游戏管理器而做的，直接拿去用会下载不到任何东西：

- 种子内记录的根目录名称是 `Bin64`，但官方 CDN 实际上把文件放在另一个文件夹之下。一般 BT 工具会按规格向 `Bin64/` 请求文件，结果每一个都找不到。
- 游戏管理器从不做种，所以也没有其他分享者可以补上。

MapleLink 只把根目录名称改成 CDN 的实际路径，其余内容一律不动，包括每一块数据的哈希值与 web seed 地址。换言之，你的下载工具仍然是以官方公布的哈希值校验每一个字节，我们无法在中间夹带任何东西。

<details>
<summary>可以给我一条 magnet 链接吗？</summary>

不可以。magnet 链接本身只是一个指向，里面没有文件清单与哈希值，下载工具要靠其他分享者把这份数据传过来。这个种子没有任何人做种，所以用 magnet 链接只会一直停在「正在下载元数据」。

种子文件内的那份清单有 430 KB（1263 个文件的路径与哈希值），本来也不可能放得进一条链接里。

</details>

<details>
<summary>可以直接给我一条下载链接吗？</summary>

客户端是 1263 个独立文件，官方没有把它们打包成单一个文件，所以没有「一条链接下载全部」这回事。种子文件就是用来把这 1263 个文件交给下载工具处理的。

如果你只需要补一两个文件，用上面的[修复](#repair)会比较直接。

</details>

<details>
<summary>下载完成后可以把文件夹搬走或改名吗？</summary>

可以。文件夹是你的，名称与位置都由你决定，改完之后记得在 MapleLink 的「设置 → 游戏路径」重新指向 `MapleStory.exe` 即可。

</details>
