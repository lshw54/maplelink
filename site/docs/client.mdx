# 遊戲客戶端

新楓之谷的完整客戶端約 67 GB，官方並沒有提供單一個安裝檔。beanfun 遊戲管理員的做法，是按一份官方清單把整個遊戲資料夾從官方 CDN 取回來。MapleLink 可以把同一份來源整理成一個 BT 種子檔，讓你用自己的下載工具取得，過程中不經任何第三方重新打包。

:::tip MapleLink 不會下載或改寫任何遊戲檔案
它只會讀取官方清單，產生一個種子檔讓你儲存。實際下載由你的下載工具直接向官方伺服器進行，每一個位元組都會以官方公佈的雜湊值核對。
:::

## 你屬於哪一種情況

| 情況 | 建議 |
|---|---|
| 全新安裝，或換一台電腦 | 用下面的[完整客戶端種子](#torrent) |
| 客戶端損壞、更新失敗、開啟時提示檔案毀損 | 用[修復現有客戶端](#repair)，只補回對不上的部分 |
| 只想要官方安裝檔或更新檔 | 同一個視窗下方就是 beanfun 官方連結 |

## 取得種子檔 {#torrent}

這個功能需要較新版本的 MapleLink。如果在工具箱找不到，請先更新到最新版。

1. 開啟 MapleLink，按右上角的工具箱圖示。
2. 選「下載／修復客戶端」。
3. 最上方的「完整客戶端（BT 種子）」會顯示目前版本、容量與發布日期。
4. 按「儲存種子檔」，選一個位置存起來。

版本號與資料夾名稱每次都是即時向官方讀取，所以這一步永遠對應當下的最新版本，不需要我們另行更新。

## 用下載工具取得客戶端

1. 安裝一個 BT 下載工具，例如 [qBittorrent](https://www.qbittorrent.org/)。
2. 用它開啟剛才儲存的種子檔。
3. 選擇儲存位置。你可以順便把根目錄改成自己想要的名稱，例如 `MapleStory`，不會影響下載。
4. 開始下載。完成後會得到一個完整的客戶端資料夾。
5. 回到 MapleLink，在「設定 → 遊戲路徑」指向該資料夾內的 `MapleStory.exe`。

種子內含指向 beanfun CDN 的 web seed，即使沒有其他分享者，也會直接由官方伺服器下載。若你使用遊戲加速器，這些流量走的是 beanfun 網域，通常同樣會被加速。

## 修復現有客戶端 {#repair}

客戶端有檔案損壞時，不需要重新下載整個 67 GB。同一個種子檔可以逐塊核對你現有的資料夾，只補回對不上的部分。

1. 先關閉遊戲，並確認沒有其他程式正在使用該資料夾。
2. 用下載工具開啟種子檔。
3. 儲存位置選你現有客戶端資料夾的**上一層**。例如客戶端在 `D:\Games\MapleStory`，這裏就選 `D:\Games`。
4. 把種子的根目錄名稱改成你現有資料夾的名稱，即上例的 `MapleStory`。
5. 加入之後，對該任務執行「強制重新檢查」（qBittorrent 為右鍵選單的 Force recheck）。
6. 檢查完成後，工具只會重新下載對不上的部分。

:::warning 修復會覆寫對不上的檔案
如果你自行修改過客戶端內的檔案，這一步會把它們還原成官方版本。有需要請先備份。
:::

核對以約 4 MB 為一塊進行，所以補回的份量會比損壞的檔案本身略多一點，但仍然遠少於重新下載整個客戶端。

## 為什麼種子檔要由 MapleLink 產生 {#why}

官方那個種子檔是為遊戲管理員而做的，直接拿去用會下載不到任何東西：

- 種子內記錄的根目錄名稱是 `Bin64`，但官方 CDN 實際上把檔案放在另一個資料夾之下。一般 BT 工具會依規格向 `Bin64/` 要檔案，結果每一個都找不到。
- 遊戲管理員從不做種，所以也沒有其他分享者可以補上。

MapleLink 只把根目錄名稱改成 CDN 的實際路徑，其餘內容一律不動，包括每一塊資料的雜湊值與 web seed 位址。換言之，你的下載工具仍然是以官方公佈的雜湊值核對每一個位元組，我們無法在中間夾帶任何東西。

<details>
<summary>可以給我一條 magnet 連結嗎？</summary>

不可以。magnet 連結本身只是一個指向，裏面沒有檔案清單與雜湊值，下載工具要靠其他分享者把這份資料傳過來。這個種子沒有任何人做種，所以用 magnet 連結只會一直停在「正在下載中繼資料」。

種子檔內的那份清單有 430 KB（1263 個檔案的路徑與雜湊值），本來也不可能放得進一條連結裏。

</details>

<details>
<summary>可以直接給我一條下載連結嗎？</summary>

客戶端是 1263 個獨立檔案，官方沒有把它們打包成單一個檔案，所以沒有「一條連結下載全部」這回事。種子檔就是用來把這 1263 個檔案交給下載工具處理的。

如果你只需要補一兩個檔案，用上面的[修復](#repair)會比較直接。

</details>

<details>
<summary>下載完成後可以把資料夾搬走或改名嗎？</summary>

可以。資料夾是你的，名稱與位置都由你決定，改完之後記得在 MapleLink 的「設定 → 遊戲路徑」重新指向 `MapleStory.exe` 即可。

</details>
