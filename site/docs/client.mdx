# 遊戲客戶端

新楓之谷的完整客戶端約 67 GB，官方並沒有提供單一個安裝檔。beanfun 遊戲管理員的做法，是按一份官方清單把整個遊戲資料夾從官方 CDN 取回來。MapleLink 內建的「遊戲客戶端管理」用的是同一份清單與同一個 CDN，可以安裝、檢查，或只補回壞掉的檔案。

:::tip 檔案來源與完整性由官方把關
清單與檔案全部來自 beanfun 官方，每個檔案下載後都會用官方公布的 SHA-256 核對，對得上才會寫入。核對不過的不會覆蓋你原有的檔案。

清單本身是公開的，想自己核對可以直接打開：[productInfo.json](https://maplestory-download.beanfun.com/maplestory/productInfo.json)。裏面每一行的檔案路徑、大小與 SHA-256，就是視窗裏比對用的那一份。
:::

## 自動下載安裝 {#install}

在「下載與安裝」分頁按**自動下載安裝**，選一個空資料夾，MapleLink 會直接從官方 CDN 取得整個客戶端。

- 過程中可以**暫停**與**繼續**，也可以取消。
- 中途關掉也不要緊：下次對同一個資料夾再檢查一次，已完成的檔案不會重新下載。
- 單一檔案連線中斷時會自動重試，最多三次；檔案不存在這類重試也無用的錯誤，則會直接列出。
- 底部的**同時下載**決定一次下載幾個檔案，預設為 6。多開連線不會增加頻寬，只是分用同一條線路：路徑較遠時多開較快；線路慢或加速器有限速時調低，單個檔案會較快完成，進度也較穩定。

完成後，到 MapleLink 的「設定 → 遊戲路徑」指向該資料夾內的 `MapleStory.exe`。

## 檢查與修復 {#repair}

在「檢查與修復」分頁選好**遊戲路徑**，再按「開始檢查」。

| 方式 | 做什麼 | 用時 |
|---|---|---|
| 快速 | 只比對檔案大小，抓得到缺失與被截斷的檔案 | 數秒 |
| 完整 | 核對每個檔案的 SHA-256 | 視硬碟而定，SSD 約數分鐘 |

檢查完會列出全部檔案，可以按「需要處理 / 正常 / 額外檔案」篩選，或直接搜尋檔名。確認要補的項目後按「下載並修復」。

修復開始後，清單會自動切換到「需要處理」：

- 下載中的檔案各有自己的進度條，進度列下方也會顯示目前正在下載的檔名。
- 完成的檔案會移到「正常」，所以「需要處理」會一路減少到零。
- 失敗的檔案會另外列在「失敗」篩選，原因寫在狀態欄。
- 完成的檔案會自動取消勾選；再按一次「下載並修復」，就只會補回剩下的。

:::warning 修復會覆寫對不上的檔案
開始前請先關閉遊戲。若你自行修改過客戶端內的檔案，請先備份。清單以外的檔案預設只會列出來給你參考；只有你在「額外檔案」勾選並確認後，才會移至資源回收筒，隨時可以還原。
:::

這個分頁的遊戲路徑只影響這個視窗，不會改動「設定」裡的遊戲路徑。

<details>
<summary>「檔案損壞」或「版本過舊」是不是代表壞了？</summary>

狀態欄會寫明每個檔案要換的原因：**缺失**是本機找不到，**版本過舊**是客戶端比官方版本舊，**檔案損壞**是版本一樣但內容對不上，**無法讀取**多數是檔案正被佔用。把游標移到狀態上會看到詳細說明。

對不上不一定代表壞了。官方清單是該版本的**基礎**客戶端，而遊戲自己的更新程式會在安裝後修改部分檔案，最典型的就是 `MapleStory.exe`。MapleLink 認得這種情況：它會向官方更新伺服器確認目前的主程式，對得上就當作正常。

若遊戲目前運作正常，這類項目可以不勾選。修復會把它們還原成基礎版本，遊戲下次啟動時通常會重新套用更新。

</details>

<details>
<summary>可以自動檢查嗎？</summary>

可以。第一次開啟視窗時會問你要不要「每次開啟時自動檢查」，選了之後可以在底部的「自動檢查」隨時改。開啟後，視窗一打開就會跑一次快速檢查。

如果你有開啟「阻止遊戲自動更新」，被擋下來的更新提示裏也有一個按鈕，直接帶你到這個視窗。

</details>

## 整理額外檔案 {#extra}

「額外檔案」列出遊戲資料夾內、但不在官方清單上的檔案，例如記錄檔、截圖、舊版殘留，或其他程式放進來的檔案。預設不會動它們。

想清掉的話，勾選要移走的檔案，按「移至資源回收筒」並確認：

- 檔案是移到**資源回收筒**，不是直接刪除，隨時可以還原。
- 官方清單上的檔案一律不會被移走，即使檔名大小寫不同也一樣；資料夾與連結也不會。
- 請先關閉遊戲。正被使用的檔案會移不走，畫面上會列出原因，並保留勾選。

:::warning 不確定就不要勾
額外檔案可能是你自己的設定，或其他程式需要的檔案。只移走你認得的東西。
:::

## 清單來源與網路 {#network}

視窗頂部的四欄會直接顯示目前狀況：

| 欄位 | 內容 |
|---|---|
| 新楓之谷 | 官方版本、發布日期與主程式日期 |
| 本機客戶端 | 這個資料夾是否為最新版本，以及上次檢查有多少檔案相符 |
| 磁碟空間 | 所在磁碟的可用空間，以及完整安裝或這次修復所需的空間 |
| 網路 | 下載線路的出口地區、官方 CDN 的延遲，以及是否經過系統代理 |

### 官方清單從哪裏取得

官方清單有兩個來源：beanfun 直接提供的位址，以及遊戲管理員使用的 HiNet 目錄。部分加速器只連得上其中一個。

「清單來源」預設為**自動**：先用上次成功的來源，失敗才改用另一個，並記住可用的那個。每個來源遇到連線中斷或逾時，都會先重試一次。

也可以手動選 **beanfun** 或 **HiNet 目錄**。此時只會使用該來源，失敗也不會自動改用另一個，方便判斷是哪一邊連不上。

按「測試來源」會同時向兩個來源各取得一次清單，顯示能否連上、花了多久與版本，例如：

> beanfun ✓ 0.4 秒　HiNet 目錄 ✗ 逾時

測試結果會用於自動模式：目前優先的來源失敗、另一個成功時，之後就會先用成功的那個。若視窗正在使用本機副本，測試到可用的來源後也會立即重新取得清單。

### 加速器與系統代理

下載、取得清單與測試，都會依照 Windows 的系統代理設定連線，與瀏覽器相同。靠設定系統代理運作的加速器或代理工具，因此會一併生效。

若加速器是按程式攔截流量，而不是設定系統代理，「網路」欄會顯示「未設系統代理」，但連線其實仍會經過加速器。PAC 自動設定指令碼不會套用，「網路」欄會註明。

### 連不上時的本機副本

每次成功取得清單，MapleLink 都會在本機保存一份副本。之後連不上官方時，會改用這份副本，並以黃色提示標明副本的日期：仍然可以照常檢查，但補回檔案還是需要連線。

<details>
<summary>可以把清單副本傳給連不上的朋友嗎？</summary>

不需要，也不建議。請對方先按「測試來源」，或把「清單來源」改成另一個，大多數情況都能直接取得。

另外，MapleLink 只接受下載位址是 beanfun 官方 CDN（HTTPS）的清單。被改過、指向其他位址的副本會被拒絕；來路不明的副本請不要使用。

</details>

## 手動：用種子檔 {#torrent}

想自己控制下載，就在「下載與安裝」分頁按**手動：儲存種子檔**，再用自己的 BT 工具開啟。

1. 安裝一個 BT 下載工具，例如 [qBittorrent](https://www.qbittorrent.org/)。
2. 用它開啟剛才儲存的種子檔，選擇儲存位置。根目錄可以改成你想要的名稱。
3. 下載完成後會得到一個完整的客戶端資料夾。
4. 回到 MapleLink，在「設定 → 遊戲路徑」指向該資料夾內的 `MapleStory.exe`。

種子內含指向 beanfun CDN 的 web seed，即使沒有其他分享者，也會直接由官方伺服器下載。

同一個種子檔也可以用來修復：把儲存位置指向現有客戶端的**上一層**，根目錄名稱改成現有資料夾的名稱，加入後執行「強制重新檢查」，工具就只會補回對不上的部分。

## 為什麼種子檔要由 MapleLink 產生 {#why}

官方那個種子檔是為遊戲管理員而做的，直接拿去用會下載不到任何東西：

- 種子內記錄的根目錄名稱與官方 CDN 的實際路徑不符，一般 BT 工具會依規格去要檔案，結果每一個都找不到。
- 遊戲管理員從不做種，所以也沒有其他分享者可以補上。

MapleLink 只把根目錄名稱改成 CDN 的實際路徑，其餘內容一律不動，包括每一塊資料的雜湊值與 web seed 位址。換言之，你的下載工具仍然是以官方公布的雜湊值核對每一個位元組。

<details>
<summary>可以給我一條 magnet 連結嗎？</summary>

不可以。magnet 連結本身只是一個指向，裏面沒有檔案清單與雜湊值，下載工具要靠其他分享者把這份資料傳過來。這個種子沒有任何人做種，所以用 magnet 連結只會一直停在「正在下載中繼資料」。

</details>

<details>
<summary>那個「遊戲橘子遊戲管理器」要不要裝？</summary>

不建議。安裝或更新它會把 `gamaniagames://` 的登錄機碼設回自己；若你有開啟 MapleLink 的網頁啟動接管，接管就會失效，要回設定重新開啟。安裝與更新用上面兩種方式已經涵蓋。

</details>
