# 新手教學

從下載到進入遊戲，約五分鐘。依序完成即可。

## 1. 下載

到[下載頁](/download)。第一次使用請選 **MapleLink-Setup.exe**，其他情況見該頁的「選擇檔案」。

:::tip 只從本站或 GitHub Releases 下載
從其他地方取得的檔案都不是我們發出的。下載後可以[核對 SHA256](/download#verify)。
:::
## 2. 解壓並放好

雙擊 `MapleLink-Setup.exe`，選擇一個位置解壓，例如 `D:\Games\`。解出的資料夾只有程式本身和一份說明；設定與帳號不會存在這裏，所以程式放在哪裏、之後要不要搬，都沒有影響。

<details>
<summary>各項資料存放在哪裏</summary>

| 位置 | 內容 |
|------|------|
| 你解壓的資料夾 | `MapleLink.exe` 程式本身，加一份「webview2報錯看這.txt」 |
| `%APPDATA%\com.maplelink.app\` | `config.ini` 設定、`accounts.dat` 與 `accounts.key` 加密後的帳號密碼、`lr\` 區域模擬用的 Locale Remulator 檔 |
| `%LOCALAPPDATA%\com.maplelink.app\` | `logs\maplelink.log` 日誌、`EBWebView\` WebView2 快取 |

要開啟這些位置，按 <kbd>Win</kbd>+<kbd>R</kbd>，貼上路徑（例如 `%APPDATA%\com.maplelink.app`）再按 Enter。

自動更新只會替換 `MapleLink.exe`，不會動到上面兩個資料夾。重灌或更換電腦時，請用工具箱的「匯出備份」，不要直接複製 `accounts.dat`，它與原本的電腦綁定。

</details>

雙擊 `MapleLink.exe`，然後選擇語言與地區（HK 或 TW）。第一次開啟可能遇到以下情況：

</details>
<details>
<summary>視窗全白，或一開啟就關閉</summary>

電腦缺少 WebView2。依[常見問題的步驟](/faq#webview2)安裝，約一分鐘。

</details>

<summary>程式詢問是否改名為 Beanfun.exe</summary>

部分網遊加速器只認得這個檔名。同意改名不影響任何功能；不使用加速器可以略過。

## 4. 登入

在登入頁右上角可以切換地區。下面是可以操作的登入頁，試試切換旗標、填入帳密：

<DemoLogin />

### HK

輸入 Beanfun 帳號與密碼。已啟用雙重驗證的帳號，再輸入驗證器上的六位數字。圖形驗證碼由程式自動處理，失敗時才需要手動輸入。

勾選「記住密碼」後，下次帳號會出現在左側列表，點選即可登入。

### TW

三種方式任選其一：

- **QR Code**：用手機的 beanfun! App 掃描畫面上的 QR Code，在手機上確認。
- **GamaPass**：依畫面指示在 GamaPass App 完成驗證。
- **帳號密碼**：需要通過 reCAPTCHA，程式會開啟一個小視窗讓你完成。

## 5. 設定遊戲路徑

第一次啟動遊戲前，到工具箱的「設定」指定 `MapleStory.exe` 所在的資料夾。程式會先嘗試自動偵測，偵測不到時才需要手動選擇。工具箱在標題列右上角的 🛠。

還沒有安裝遊戲，或客戶端損壞需要修復，見[遊戲客戶端](/client)。

<DemoSettings focus="path" />

## 6. 取得 OTP，啟動遊戲

登入後，主頁右側會列出這個帳號下的遊戲帳號。點選一個，再按「取得 OTP」：

<DemoAccounts />

- 預設會複製到剪貼簿；
- 開啟「自動輸入」後，程式會直接填入遊戲登入視窗。

OTP 有時效，取得後請立即使用。

然後按主頁左側的圓形按鈕啟動遊戲：

<DemoPlay />

<details>
<summary>只想啟動遊戲，在遊戲內自行登入</summary>

登入頁有「直接啟動遊戲」，不需要先登入任何帳號。

</details>
## 進階功能

熟悉基本操作後，可以再試以下功能：

<details>
<summary>多帳號與多 Session</summary>

按分頁列右邊的「+」可以再登入一個帳號，地區不同也可以；每個分頁各自有帳號列表、OTP 與啟動按鈕。帳號卡片可拖曳排序、右鍵改名。

<DemoSessions />

</details>
<details>
<summary>區域模擬</summary>

自動進行，沒有開關。系統地區不是繁體中文時，程式啟動遊戲會自動經 Locale Remulator 注入，不需另外安裝或設定。

</details>
<details>
<summary>阻止自動更新</summary>

在工具箱「進階」開啟後，遊戲啟動時自動關閉 `Patcher.exe`。平時建議保持關閉。

<DemoSettings focus="patcher" />

</details>
<details>
<summary>懷舊服</summary>

在服務列表選「經典版」。程式會檢查 Nexon Game Manager 是否已安裝，按「啟動」自動完成 SSO 並開啟遊戲。

</details>
<details>
<summary>攔截網頁啟動</summary>

只能用網頁登入（例如經 UU／VPN）時使用。在登入頁按登入鈕右邊的地球圖示進入設定頁，開啟開關後，在瀏覽器登入 beanfun 官網並按「開始遊戲」，會改由 MapleLink 開遊戲並貼入 OTP。

<DemoWebLaunch />

</details>
<details>
<summary>更換電腦</summary>

帳號存放在 `%APPDATA%\com.maplelink.app\accounts.dat`，以 Windows DPAPI 加密並綁定原本的電腦，無法直接複製。在工具箱「帳號管理」按「匯出資料」，再於新電腦「匯入資料」。

<DemoBackup />

</details>
遇到問題請先查看[常見問題](/faq)；找不到答案，到 [GitHub Issues](https://github.com/lshw54/maplelink/issues) 回報。
